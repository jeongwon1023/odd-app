# ODD 데이트 코스 리서치 데이터베이스
> 수집일: 2026.06.26 | 출처: 네이버 블로그, 마리끌레르, GQ Korea, Trip.com, 식신, 다이닝코드, KKday, SNS 등
> 용도: AI 코스 추천 로직 개선 시 실제 사용자 데이트 패턴 참조 데이터

---

## 📌 이 파일의 사용법
- `gemini_service.dart` 아키타입/프롬프트 개선 시 참조
- `naver_place_service.dart` 쿼리 키워드 개선 시 참조
- Supabase 큐레이션 DB 구축 시 시드 데이터로 활용
- 각 코스는 `OPEN(카페) → PEAK(경험) → CLOSE(식사)` 3슬롯 구조와 매핑됨

---

## 🌸 카테고리 1: 감성 로맨스 (Archetype: 감성 로맨스 / 힙스터 컬처 / 인스타 포토)

### 정의
> 분위기·조명·공간 감성이 최우선. 인스타그램 포토 퀄리티, 감각적인 인테리어, 낭만적인 저녁 흐름이 핵심.
> 20-30대 여성이 주도권을 가지고 선택하는 데이트 유형.

---

### 코스 A: 성수동 인더스트리얼 감성 코스

**대상**: 커플 전반 | **소요**: 5~7시간 | **예산**: 1인 4~6만원

| 슬롯 | 장소 | 설명 |
|---|---|---|
| OPEN | **오르에르(Or.er)** | 성수 대표 빈티지 카페. 높은 천장+자연광, 인생샷 스팟. 시그니처 오르에르 라테 |
| OPEN 대안 | **어니언 성수** | 독립출판+카페. 감성 극강, 줄 서는 곳 |
| PEAK | **대림창고** | 옛 창고 개조 복합문화공간. 전시+공연+사진. 성수 PEAK 최적 |
| PEAK 대안 | **포인트오브뷰** | 연무장길 문구샵+전시. 층마다 주제 다름. 감성 쇼핑+관람 |
| CLOSE | **성수플레이트** | 인더스트리얼 인테리어, 파스타·스테이크 |
| CLOSE 대안 | **대림창고 다이닝바** | 와인+칵테일+식사. 저녁 분위기 최고 |

**동선**: 뚝섬역 → 오르에르(도보5분) → 연무장길 산책 → 대림창고 → 성수플레이트

### 코스 B: 한남동 아트+럭셔리 코스

**대상**: 감성+고급 커플 | **소요**: 5~7시간 | **예산**: 1인 6~10만원

| 슬롯 | 장소 | 설명 |
|---|---|---|
| OPEN | **아우프글렛 한남** | 미드센추리 무드+통창 자연광. 커피 퀄 높음 |
| OPEN 대안 | **카페 드 파리 한남** | 파리 감성, 루프탑 있음 |
| PEAK | **리움미술관** | 고미술(M1)+현대미술(M2). 2~2.5시간 관람. 커플 데이트 최적 |
| PEAK 대안 | **논픽션 한남 쇼룸** | 프래그런스 브랜드 체험. 서로 향수 추천하며 취향 공유 |
| PEAK 대안2 | **한남동 예술길 산책** | 한강진역→리움→이태원역 방향. 갤러리들 산책하며 관람 |
| CLOSE | **빠르크 한남** | 한식. 세계 탑 아티스트 단골. 건강한 감칠맛 |
| CLOSE 대안 | **이태원 파인다이닝 거리** | 이탈리안·인도·멕시칸 등 세계 각국 레스토랑 밀집 |

**동선**: 한강진역 1번 출구 → 아우프글렛 → 논픽션 쇼룸 → 리움 → 빠르크

### 코스 C: 을지로 힙지로 레트로 감성 코스

**대상**: 힙스터 커플 | **소요**: 저녁 집중 | **예산**: 1인 4~7만원

| 슬롯 | 장소 | 설명 |
|---|---|---|
| OPEN | **카페 적당** | 조도 낮음+테이블 초+프라이빗. 을지로 감성 정수 |
| OPEN 대안 | **바캉스 커피** | 나진빌딩 9층. 블루 큐라소+로즈메리 시그니처 라테 |
| OPEN 대안2 | **호랑이커피** | 을지로 대표 커피 맛집 |
| PEAK | **문화역서울 284** | 옛 서울역사 복합문화공간. 전시+공연 |
| PEAK 대안 | **을지로 골목 투어** | 인쇄소·철공소 골목+벽화. 인스타 포토 |
| CLOSE | **을지로 노가리 골목** | 야외 테이블+생맥주+골목 낭만 |
| CLOSE 대안 | **배고픈청춘** | 낮=카페, 저녁=와인바+라이브 공연. 힙지로 정수 |
| CLOSE 대안2 | **바 만리향** | 칵테일+와인. 제조 과정 관람 가능 |

**동선**: 을지로3가역 → 카페 적당 → 문화역서울 → 노가리 골목 → 배고픈청춘

### 코스 D: 홍대-연남동 감성 산책 코스

**대상**: 활발한 커플 | **소요**: 5~8시간 | **예산**: 1인 3~5만원

| 슬롯 | 장소 | 설명 |
|---|---|---|
| OPEN | **바이앤드 커피(Viand Coffee)** | 재즈음악+여유로운 분위기. 마포구 독막로7길 |
| OPEN 대안 | **콘하스** | 조용+힙. 마포구 연희로 1-1 |
| PEAK | **경의선 숲길(연트럴파크) 산책** | 연남동→홍대 이어지는 숲길. 서울 중심부 데이트 산책 필수 코스 |
| PEAK 대안 | **공방 체험** (오포르쇼룸 팔찌 만들기) | 홍대 근처 커플 체험 공방 |
| CLOSE | **치쿠린 서울** | 닭요리 이자카야. 사케+나베 조합 |
| CLOSE 대안 | **뉴올 재즈 라운지** | 재즈+뇨끼+하몽+와인. 홍대에서 유일한 고퀄 재즈 라운지 |

**동선**: 홍대입구역 → 바이앤드 커피 → 경의선 숲길 산책 → 오포르쇼룸 → 치쿠린 서울

### 코스 F: 인사동-북촌 한국 전통 감성 코스

**대상**: 전통+감성 조합 커플 | **소요**: 5~7시간 | **예산**: 1인 5~8만원

## ⚡ 카테고리 2: 액티비티 챌린지 (Archetype: 액티비티 챌린지 / 인스타 포토)

### 정의
> 몸을 쓰거나 게임형 도전 경험이 중심. 함께 승부를 겨루거나 협력하는 과정에서 친밀감 형성.
> 20-30대 ENFP/E형 커플, 연애 초반에 특히 유효.

---

### 코스 A: 홍대 방탈출 + 이자카야 코스

**대상**: 연애 초반 ~ 중반 | **소요**: 저녁 3~5시간 | **예산**: 1인 4~6만원

| 슬롯 | 장소 | 설명 |
|---|---|---|
| OPEN | **오스카 커피부스 (홍대)** | 우드톤, 대화하기 좋은 커피 부스. 긴장 풀기 |
| PEAK | **비밀의 숲 (홍대)** | 5개 테마 방탈출. 홍대역 9번 출구 도보 8분. 어비스/OVERKILL/드림레일/BESTSELLER/리플레이 |
| PEAK 대안 | **딥띵커 (홍대)** | '옹이의 꿈' 테마. 홍대 최고 방탈출 평판 |
| CLOSE | **치쿠린 서울** | 닭요리 이자카야. 방탈출 후기 안주 삼아 대화 최적 |
| CLOSE 대안 | **뉴올 재즈 라운지** | 재즈+와인+하몽. 방탈출 흥분 가라앉히기 좋음 |

## 🌿 카테고리 3: 로컬 힐링 (Archetype: 로컬 힐링 / 감성 로맨스)

### 정의
> 바쁜 일상에서 벗어나 속도를 늦추는 데이트. 자연, 전통, 소소한 공방, 여유로운 카페가 핵심.
> 연애 중반 이상, 조용한 성격의 커플, 재충전이 필요한 커플에게 최적.

### 코스 A: 인사동-북촌 한옥 힐링 코스

**대상**: 여유 있는 커플 | **소요**: 5~7시간 | **예산**: 1인 4~6만원

| 슬롯 | 장소 | 설명 |
|---|---|---|
| OPEN | **오설록 티하우스 인사동** | 제주 녹차 티+디저트. 차분하고 여유로운 시작 |
| OPEN 대안 | **인사동 전통 찻집 다담** | 한방차+전통 공간 |
| PEAK | **커플 공예 클래스** | 팔찌/비즈/걱정인형/커플 머그컵 만들기. 인사동 내 공방 다수 |
| PEAK 대안 | **북촌한옥마을 산책** | 가회동 골목+북촌8경. 느릿느릿 사진 찍으며 걷기 |
| CLOSE | **북촌손만두** | 50년 전통 수제 만두. 따뜻하고 든든 |
| CLOSE 대안 | **삼청동 한식 레스토랑** | 안국역 주변 분위기 좋은 한식 |

| PEAK 대안 | **도예/공방 체험** (성수 근처) | 손으로 만드는 힐링 |
| CLOSE | **성수 분위기 좋은 레스토랑** | 성수플레이트 or 분위기 있는 이탈리안 |

## 🔑 핵심 인사이트: 실제 사용자 데이트 패턴

### 1. OPEN 슬롯 (카페)의 진짜 역할
- 단순히 커피 마시는 곳이 아님
- **"이 데이트의 분위기 세팅"** 역할
- 감성 로맨스: 조명 낮고 대화하기 좋은 곳 (카페 적당, 아우프글렛)
- 액티비티: 에너지 충전용 (빠르게 마시고 이동)
- 힐링: 느긋하게 앉아 있는 공간 (오설록, 전통 찻집)

### 2. PEAK 슬롯의 진짜 역할
- **"함께 공유하는 경험"** — 사진 찍기, 뭔가 만들기, 같이 도전하기
- 감성 로맨스: 전시/갤러리/공방 — 취향을 알아가는 계기
- 액티비티: 방탈출/볼링/VR — 함께 흥분, 승부, 협력
- 힐링: 산책/공방 — 같이 손으로 만들거나 느릿느릿 걷기
- **PEAK 장소가 코스의 핵심 기억이 됨**

### 3. CLOSE 슬롯의 진짜 역할
- **"오늘의 감성을 마무리하는 저녁"** — PEAK의 여운을 이어가야 함
- 감성 로맨스 → 분위기 있는 이탈리안/와인바/이자카야
- 액티비티 → 고기집/이자카야 (배고프고 피로, 든든하게)
- 힐링 → 한식/소박한 레스토랑

### 4. 카테고리 정합성 실패 원인 (현재 ODD 문제)
- API 검색 키워드가 너무 광범위해서 **카테고리와 맞지 않는 장소가 섞임**
- "분위기 좋은 레스토랑 검색" → 맥도날드 포함
- "PEAK = 전시" 키워드인데 전시가 없는 지역에선 엉뚱한 장소 반환
- **해결책: 아키타입별 전용 키워드 세트 + 브랜드 블랙리스트**
